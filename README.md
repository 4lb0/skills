## 🎤 entrevista

```
npx skills add https://github.com/4lb0/skills --skill mentor
```

Simulador conversacional de entrevistas laborales con nivel profesional. El
usuario pasa su CV y el puesto al que quiere aplicar. Analiza el perfil,
determina el nivel, detecta el tipo de entrevista y simula una entrevista
completa con scorecard interna, profundidad progresiva, red flags, presión
realista y un informe final detallado con probabilidad de pasar cada etapa.
Soporta modos: Full Interview, Behavioral, Live Coding, System Design y
Negociación Salarial.

## 📰 crear-diario

```
npx skills add https://github.com/4lb0/skills --skill crear-diario
```

Convierte una nota o artículo periodístico en un HTML imprimible con formato de
diario (masthead, volanta, titular, copete, firma, columnas, letra capital y
citas destacadas), listo para imprimir o guardar como PDF en A4. Genera
`print.html` (multipágina, una hoja A4 por página) y, si se pide "en una sola
página" o una "versión resumida", genera `print_v2.html` (todo en una única
hoja).
