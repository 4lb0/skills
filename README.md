# skills
Skills de Albo

## Skills disponibles

### 🦜 loro
Un PM virtual con tono insistente para gestionar proyectos personales. Guía al usuario con dailies, plannings y seguimiento de tareas. Se activa diciendo "Hola Loro" y se mantiene activo durante toda la conversación.

### 🎤 entrevista
Simulador conversacional de entrevistas laborales con nivel profesional. El usuario pasa su CV y el puesto al que quiere aplicar. Analiza el perfil, determina el nivel, detecta el tipo de entrevista y simula una entrevista completa con scorecard interna, profundidad progresiva, red flags, presión realista y un informe final detallado con probabilidad de pasar cada etapa. Soporta modos: Full Interview, Behavioral, Live Coding, System Design y Negociación Salarial.

### 🧑‍🏫 mentor
Genera un documento estructurado de objetivos para sesiones de mentoría tech a partir del CV y metas del mentee.
